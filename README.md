# B75 Web Application

## Project Overview
B75 Web Application is a Java-based web application developed using Java, JSP, Servlets, JDBC, and MySQL.

This project demonstrates user registration, login authentication, session management, and navigation to a home page.

## Technologies Used
- Java
- JSP (Java Server Pages)
- Jakarta Servlets
- JDBC
- MySQL
- Apache Tomcat 10
- Eclipse IDE
- HTML

## Features
- User Login
- User Authentication
- Session Management
- Home Page Navigation
- Database Connectivity

## Tools Required
- JDK 25
- Eclipse IDE
- Apache Tomcat 10.1
- MySQL Database

## How to Run
1. Clone or download the repository.
2. Import the project into Eclipse IDE.
3. Configure Apache Tomcat Server.
4. Configure MySQL database connectivity.
5. Run the project on the Tomcat server.
6. Open the application in your browser.
